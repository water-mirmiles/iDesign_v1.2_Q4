## 已知缺口

- 复制项目目前复制项目记录，不复制原画布草稿。不得称为完整工程复制。
- JSON 当前包含 project/nodes/positions/history，未单独包含设计描述与所有视图参数；无导入入口，不能称为完整可恢复备份。
- SVG 导出尚未完整采用拖动后的坐标、节点 CSS 变化和全部视图状态；图片下载主要是源图，不是包含 CSS 滤镜的合成设计结果。
- 普通 localStorage 保存异常尚未统一处理；大图仍可能耗尽浏览器配额。上传有 8MB/张检查，不代表累计配额足够。
- 元素提取确认记录历史并打开预置资源库，不是真实分析或保存提取资产。
- 存在面板比例/分辨率入口和缺图占位，真实能力尚未连接；单元/主流程回归不等于这些能力完成。
- 24 屏完整像素基线、键盘/焦点可访问性、完整移动端适配尚未验收。

以上保留为下一阶段 P0 输入。本轮建立流程和现状台账，不无授权扩大为全面功能整改。正式 AI、法务、3D、PDM/ERP、公司存储、登录/权限、共享版本及经营接口均未接入。
