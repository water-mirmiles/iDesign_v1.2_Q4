# iDesign 产品需求文档

文档版本：1.0 · 工程基线：0.1.0 · 最后更新：2026-10-11 · 当前迭代：ITER-001。

## 目标与依据

建立面向鞋履设计师及 CT 团队的设计工作台：项目中心 → 产品参考 → 无限画布 → 创作分支/元素 → 设计交付；经营管理通过看板查看覆盖与转型进度。此次先建立截图复刻的工程与开发流程基线，真实企业能力分阶段接入。

历史理解依据为此前 iDesign PRD、设计最后一公里调研、正式平台看板、项目/评审中心讨论；这些作为背景。当前页面及交互范围以用户此次 24 张截图为准，历史方案与截图冲突时须记录再澄清，不能自行移植 iAMZ 的 A+ 功能。截图中的 2026 日期、数字和品牌是演示基准，不证明真实后台数据。

用户角色：设计师创建并迭代作品；CT 负责人查看品牌项目与统计；未来评审/法务/开发团队处理审核和打样。当前“设计师”身份为本地演示，正式角色权限未实现。

## 状态约定

“目标”是产品需求；“本地实现”表示代码已具备该范围；“演示”表示无真实服务；“未接入”表示能力缺失；“待用户验收/已验收”必须有对应证据。详细实现事实在 [FEATURES](FEATURES.md)，测试和受阻在 [TESTING](TESTING.md)，不在本文件堆叠历轮日志。

## 数据与约束

- 当前实体：项目含 id/name/type/status/image/source/date/Brief/款号；画布含节点、坐标、历史和描述。稳定 ID 与显示名分离。
- 本地键：`idesign-theme`、`idesign-projects`、`idesign-trash`、`idesign-canvas-<项目ID>`。不同域名/端口/浏览器存储隔离；清空浏览器数据会丢草稿。
- 草稿、源图、生成任务和不可变版本未来须分离；存储异常不能显示保存成功。兼容迁移须先备份，不能重置旧用户数据。
- 真实服务配置齐全不等于已验证鉴权、额度或效果。收费任务不得自动回退模型/重试。
- 当前无需登录、服务器或密钥；正式功能按 REQ-016 单独定义契约和验收，不将静态站点发布算正式企业上线。
